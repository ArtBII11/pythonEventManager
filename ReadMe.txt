Этот проект основан на кейсе из кейс-фестиваля 

Ссылка на кейс (стр.9 , название "Event manager на Python" №215) : https://radar-mms.com/upload/medialibrary/d21/znig5cr12btj6ud16xeimfugc2akr1n2.pdf 
Ту программу , которая в файле называется "Болванчик". Она сделана для схематичного показа функционала приложения , а не его дизайн
(То есть она создана только для теста функций и их создания)
Запуск осуществляется с MAIN_EM2
MAIN_EM1 - это пример главного окна приложения 
MAIN_EM2 - это пример окна создания и отправки приглашений по почте

Он создан для упрощения планирования каких-либо мероприятий через почту

Функции приложения :
1)	Назначение даты
2)	Создание списка гостей
3)	Рассылка по почтам гостей приглашения для мероприятия
4)	Создание списка участников 
5)	Назначение ролей участников
6)	Рассылка по почтам участников об их роле и дальнейшей информацией о мероприятии
7)	Умение создавать бюджет для мероприятия
8)	Умение распределять бюджет, а именно покупки для создания мероприятия
9)	Умение проверять, что бюджет не выходит за лимиты
10)	Дизайн приложения. Удобная навигация через все вкладки, окна приложения

В данный момент не сделан пункты : 7, 8, 9 и 10.
